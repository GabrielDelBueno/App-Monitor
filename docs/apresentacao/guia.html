APP MONITOR / GUIA DE USO · 1/22

APP Monitor

Tecnologia da escola, organizada em um só lugar.

  1. Acompanhe os equipamentos e os empréstimos.
  2. Professor: solicite, utilize e devolva.
  3. Administrador: gerencie, aprove e confira.
Guia com telas demonstrativas do aplicativo.
APP MONITOR / VISÃO GERAL · 2/22

Quem faz o quê?

Cada perfil tem suas funções.

  1. Professor: agenda, acompanha e registra a utilização.
  2. Administrador: gerencia usuários e inventário; também opera as liberações.
  3. TI: aprova, libera e confere os aparelhos.
O cadastro público cria somente contas de Professor.
APP MONITOR / VISÃO GERAL · 3/22

O caminho de um empréstimo

Do pedido ao relatório final.

  1. 1. Professor solicita → equipe aprova.
  2. 2. Equipe libera → professor utiliza.
  3. 3. Professor devolve → equipe confere.
  4. 4. As contas responsáveis assinam o relatório.
A liberação ocorre no dia do agendamento.
APP MONITOR / TODOS OS PERFIS · 4/22

Como entrar no app

Use o navegador do computador ou celular.

  1. 1. Abra o endereço do App Monitor.
  2. 2. Informe seu e-mail e sua senha.
  3. 3. Clique em Entrar.
  4. 4. Confira seu nome e perfil no cabeçalho.
Endereço: app-monitor-interface.onrender.com
APP MONITOR / PRIMEIRO ACESSO · 5/22

Professor: criar sua conta

O próprio professor pode se cadastrar.

  1. 1. Clique em Sou professor — criar minha conta.
  2. 2. Informe seu nome inteiro e e-mail.
  3. 3. Crie uma senha com pelo menos 12 caracteres.
  4. 4. Confirme a senha e clique em Criar conta de professor.
Contas de administrador e TI são criadas pela escola.
APP MONITOR / PRIMEIRO ACESSO · 6/22

Trocar a senha provisória

Para contas criadas pelo administrador.

  1. 1. Entre com o e-mail e a senha provisória recebida.
  2. 2. Digite a senha provisória no formulário.
  3. 3. Crie e confirme sua nova senha.
  4. 4. Clique em Salvar minha senha.
A troca é obrigatória antes de usar as funções do app.
APP MONITOR / PROFESSOR · 7/22

Professor: sua visão geral

Veja seus pedidos e movimentações.

  1. 1. Use Visão geral para acompanhar suas atividades.
  2. 2. Abra Agendamentos para ver os pedidos.
  3. 3. Em Meus dispositivos, acompanhe os empréstimos.
  4. 4. Consulte as notificações no sino.
O professor acompanha os próprios registros.
APP MONITOR / PROFESSOR · 8/22

Fazer um agendamento

Solicite os aparelhos para sua aula.

  1. 1. Clique em + Novo agendamento.
  2. 2. Escolha data e horário; informe a turma.
  3. 3. Selecione o tipo e a quantidade de aparelhos.
  4. 4. Clique em Salvar agendamento.
Tipos: Tablet, Notebook, Chromebook e Celular. Até 25 aparelhos por pedido.
APP MONITOR / PROFESSOR · 9/22

Acompanhar a aprovação

Confira o pedido antes de retirar os aparelhos.

  1. 1. Abra Agendamentos.
  2. 2. Pendente: o pedido aguarda aprovação da equipe.
  3. 3. Aprovado: combine a retirada com a equipe.
  4. 4. Se editar o pedido, ele volta para aprovação.
O professor solicita; a equipe registra a liberação.
APP MONITOR / PROFESSOR · 10/22

Usar e devolver os aparelhos

Registre a utilização da turma.

  1. 1. Abra Meus dispositivos → Abrir movimentação.
  2. 2. Informe o aluno associado a cada aparelho.
  3. 3. Escreva o relato da aula e das ocorrências.
  4. 4. Entregue os aparelhos e clique em Enviar devolução.
Depois do envio, a equipe precisa conferir o retorno físico.
APP MONITOR / PROFESSOR · 11/22

Assinar o relatório

Finalize o registro após a conferência.

  1. 1. Abra Relatórios e assinaturas.
  2. 2. Clique em Ver relatório e confira as informações.
  3. 3. Desenhe sua assinatura no espaço indicado.
  4. 4. Clique em Confirmar minha assinatura.
Uma assinatura de professor pendente pode impedir novos pedidos.
APP MONITOR / ADMINISTRADOR · 12/22

Administrador: visão geral

Acompanhe a operação da escola.

  1. 1. Consulte os indicadores e as notificações.
  2. 2. Abra Usuários para gerenciar os acessos.
  3. 3. Use Inventário para cuidar dos aparelhos.
  4. 4. Acompanhe pedidos, retornos e relatórios.
TI tem funções operacionais; a gestão de usuários é do administrador.
APP MONITOR / ADMINISTRADOR · 13/22

Gerenciar os usuários

Cadastre e mantenha os acessos da equipe.

  1. 1. Abra Usuários → + Novo usuário.
  2. 2. Informe nome, e-mail e perfil correto.
  3. 3. Cadastre e entregue a senha provisória em particular.
  4. 4. Use as ações da lista para editar, redefinir senha ou desativar.
Os professores também podem criar suas próprias contas na tela de entrada.
APP MONITOR / ADMINISTRADOR / TI · 14/22

Conhecer o inventário

Identifique cada equipamento.

  1. 1. Abra Inventário.
  2. 2. Pesquise controle interno, série, QR, fabricante ou modelo.
  3. 3. Abra Editar dispositivo para completar os dados.
  4. 4. Use QR para visualizar e imprimir a etiqueta.
Fabricante e modelo aparecem no inventário; os pedidos continuam por tipo.
APP MONITOR / ADMINISTRADOR · 15/22

Importar a planilha da escola

Confira a seleção antes de gravar.

  1. 1. Abra Inventário → Importar planilha.
  2. 2. Selecione o .xls exportado pelo inventário escolar.
  3. 3. Confira quantidades, conflitos e séries ausentes.
  4. 4. Clique em Importar dispositivos.
Entram somente os tipos selecionados com status Disponível; os demais ficam de fora.
APP MONITOR / ADMINISTRADOR / TI · 16/22

Aprovar um pedido

Prepare a retirada dos equipamentos.

  1. 1. Abra Agendamentos.
  2. 2. Confira professor, turma, data, tipo e quantidade.
  3. 3. Clique em Aprovar no pedido pendente.
  4. 4. No dia agendado, clique em Liberar.
Confira a disponibilidade física antes da entrega.
APP MONITOR / ADMINISTRADOR / TI · 17/22

Liberar os dispositivos

Escolha os aparelhos que serão entregues.

  1. 1. Confira o agendamento selecionado.
  2. 2. Leia o QR ou código de barras, ou digite o identificador.
  3. 3. Também é possível marcar os aparelhos na lista.
  4. 4. Confira a quantidade e clique em Liberar dispositivos.
O tipo deve corresponder ao pedido; aparelhos em uso ou indisponíveis são bloqueados.
APP MONITOR / ADMINISTRADOR / TI · 18/22

Apontar a câmera corretamente

Use a linha para escolher a etiqueta desejada.

  1. 1. Clique em Abrir câmera e permita o acesso.
  2. 2. Alinhe a etiqueta à linha vermelha central.
  3. 3. Mantenha o código completo dentro da moldura.
  4. 4. Afaste as outras etiquetas e procure boa iluminação.
A leitura aceita QR e barras com identificador cadastrado. Imagem de câmera simulada.
APP MONITOR / ADMINISTRADOR / TI · 19/22

Conferir a devolução

Confira os aparelhos recebidos.

  1. 1. Abra Movimentações e retorno → Abrir movimentação.
  2. 2. Compare os aparelhos físicos com a lista.
  3. 3. Atualize o estado e registre comentários quando necessário.
  4. 4. Clique em Concluir conferência e assine o relatório.
A devolução enviada pelo professor ainda depende desta conferência.
APP MONITOR / TODOS OS PERFIS · 20/22

Consultar o histórico e o PDF

Recupere os registros concluídos.

  1. 1. Abra Histórico.
  2. 2. Localize o empréstimo desejado.
  3. 3. Clique em Visualizar / PDF.
  4. 4. Use Imprimir / salvar PDF para guardar uma cópia.
As assinaturas são registros manuscritos de contas autenticadas, sem certificação ICP-Brasil.
APP MONITOR / TODOS OS PERFIS · 21/22

Usar no celular

O navegador já permite usar o aplicativo.

  1. 1. Abra o mesmo endereço no navegador do celular.
  2. 2. Entre com sua conta normalmente.
  3. 3. Se quiser, adicione um atalho à tela inicial.
  4. 4. Para ler etiquetas, permita o acesso à câmera.
No plano gratuito, a conexão inicial com o servidor pode demorar.
APP MONITOR / RESUMO · 22/22

Pronto para começar

Uma conta, um pedido e um registro completo.

  1. Professor: entrar → agendar → utilizar → devolver → assinar.
  2. Administrador: gerenciar → aprovar → liberar → conferir → assinar.
  3. Dificuldade com a senha? Procure o administrador.
  4. Série ausente? Confira a etiqueta S/N e complete o inventário.
