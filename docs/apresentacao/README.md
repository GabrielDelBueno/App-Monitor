# APP Monitor — Guia de uso

Apresentação de 22 slides para treinamento da escola, com instruções para Professor, Administrador e TI.

- **APP-Monitor-Guia-de-Uso.pptx:** apresentação editável no PowerPoint, com notas do apresentador.
- **APP-Monitor-Guia-de-Uso.pdf:** versão pronta para leitura, projeção ou impressão.
- **guia.html:** versão para abrir no navegador; mantenha a pasta `imagens` ao lado do arquivo. Use tela cheia e avance rolando a página.
- **roteiro.json:** títulos, passos e observações dos slides.

Conteúdo: funções de cada perfil, fluxo do empréstimo, login, autocadastro do professor, troca de senha provisória, agendamento, acompanhamento, uso/devolução, assinaturas, gestão de usuários, inventário, importação, aprovação, liberação, leitura pela câmera, conferência, histórico/PDF e uso no celular.

As imagens foram capturadas do código atual do App Monitor em 08/10/2026 usando contas, alunos e equipamentos fictícios em banco SQLite isolado. A imagem da câmera usa vídeo simulado para mostrar o alinhamento da etiqueta. Não foram acessadas contas reais nem alterado o banco da escola. As imagens não confirmam publicação de funcionalidades no serviço público.

Os links do slide de entrada e do último slide levam a https://app-monitor-interface.onrender.com. O formato PowerPoint tem proporção 16:9. Abra o `.pptx` e use **Apresentação de slides → Do começo**; os textos podem ser editados normalmente.
